## What changed

Implements lane L2 of `.harmony/specs/s-rta-0923-review-fixes-plan.md` (review fix b):
`Program::compile`'s continuous-lane branch now takes each `AutomationCurve::Breakpoint`'s
compiled `x` from its own gesture's parallel `Stamp` (`Lane.h Gesture::stamps[i]`, via the
existing `pickAt` lambda already used for discrete points) instead of always reconstructing
it from the take's sparse `TempoMap` via `convertBeatX`. The tempo map is now only a fallback
for a gesture whose `stamps.size() != curve.pts.size()` (hand-built or edited-and-stripped
take) — and that fallback is now REPORTED via the previously-declared-but-unused
`CompileReport::invalid` bucket (one `Issue` per lane, message names the mismatched gesture
count), never silent.
