2. Questions — each has a default; nothing waits on you

Decks (deck change)

Decks are now just boxes of clips; the layers hold what plays. Four edge cases:

  1. If you delete a deck while one of its clips is playing, should that clip keep playing until you fire something else on that layer? Default: yes, it keeps playing.
  2. If you load a deck that has more rows than your show has layers, should the show add the missing (empty) layers so you can see all of that deck's clips? Default: yes.
  3. Clicking a deck tab used to be an Undo step (Cmd+Z flipped you back a deck). Now that switching decks never changes the picture, Undo skips deck clicks, so Cmd+Z always undoes your last real change, like a clip you fired. OK? Default: Undo skips deck clicks.
  4. If you fire a column on a deck where some rows of that column are empty, should those layers go empty (as today) or keep what they are playing? Default: go empty, as today (Ignore Column still keeps a layer).

Also put to you earlier today, still standing unless you object: layer settings (effects, opacity, blend, transition, autopilot) belong to the layer and are shared by every deck; every deck shows the show's layer rows; the deck-to-deck fade goes away (a deck switch has nothing to fade); the layer strip shows each layer's playing clip and the deck it came from.

Record to clip

  1. When a recording lands in the top row, should it go in the first empty spot from the left, or always after the last clip in that row? Default: the first empty spot from the left.
  2. When a recording is done, should it just appear in its spot ready for you to play, or start playing by itself right away? Default: appear, ready to play.
  3. If you forget to end a recording, when should it end by itself? Default: after 64 bars (about 2 minutes at 128 BPM; up to about 0.8 GB at 1080p).
  4. If you record one layer that has see-through parts (like a logo), should the recording stay see-through? Default: no. See-through parts become black (smaller files, lighter playback).

  6. If you switch decks while a recording is running, which deck should the finished clip go into? Default: the deck you were on when you pressed REC (its top row, first empty spot).
