### A1.3 newton_3d -- mechanism VERIFIED (source + numpy; diag chain: Angle X 0.55->0.0 made it visible)
`SourceRegistry.cpp:586`: Angle X 0.55. Shader `EmbeddedShaders.h:7547-7551`: rx = 0.55*2pi + 0.3 = 3.756 rad, ro = rotY(ry)*rotX(rx)*(0, 1.5, camDist=3.59) = (-0.64, -3.29, +1.97) -- the camera is 3.3 units BELOW the heightfield (surface y = h*heightScale in [0, 0.95], `:7530-7536`). ## A4. sierpinski black at 256x256 -- mechanism VERIFIED (source + arithmetic; diag (b): 0.00 at 256, 7.76 / lit 7.51% at 512 and 1024)
It is not line width. `EmbeddedShaders.h:6564-6573`: p = fract(uv*0.5+0.5) spans exactly one unit over the frame height at Zoom 0 / Rotation 0.5; each of maxIter = 9 (`:6545-6547`, Iterations 0.5) levels tests one binary digit of p; a pixel is a hole if at ANY level both digits are 1. At 256x256 every pixel centre is (2i+1)/512 -- nine binary digits with the NINTH always 1 in both axes -- so level 9 marks every pixel a hole: black by arithmetic. At 512 the 9th digit varies and the level-9 gasket covers (3/4)^9 = 7.5% (= the measured 7.51%). It recurs on any canvas of height 2^(maxIter-1): 1024x1024 at Iterations >= 0.6 or Zoom >= 0.14, 2048 at higher settings. 1920x1080 is not dyadic and renders (contact sheet).
FIX (`:6547`, triangle branch only): after `int maxIter = min(baseIter + zoomIter, 20);` add `if (!isCarpet) maxIter = min(maxIter, int(log2(u_resolution.y * zoomPow)));` (move `isCarpet` above it). The alias needs 2^k = 2H; capping k <= log2(H*zoomPow) removes it exactly and keeps cells >= 1 px. Byte-identical at 1920x1080 for Iterations <= 0.66 (cap 10 >= default 9) and at 4K (cap 11); at 256 it renders level 8 (lit 10%), at 512 level 9 (unchanged). Carpet mode (`p *= 3`) has no dyadic alias -- untouched. Other line sources (polygon_lines, lissajous, laser_scan) draw UV-width strokes that only look dim at 256 (p99.5 98-255) -- that is H3, not an app defect.
Tests: T2 cases: sierpinski 256x256 t=1.13 (RED today, lit 0), 1920x1080 (GREEN today, pins no change), 1024x1024 with Iterations 0.75 (RED today). T3 row (b) repeated.

## A5. crystal_cavern -- DIAGNOSE first, then fix
