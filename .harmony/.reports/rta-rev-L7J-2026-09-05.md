FINDING F1 (BLOCKING-CALIBER, new code, real race, disk-verified via constructed trace):
  Pool=Favorites wires `PresetSelector::processFrame()` (GL thread, via ProjectMSource::render(),
  src/sources/ProjectMSource.cpp:148) to call `manager->getFavorites()`
  (src/sources/PresetSelector.cpp:21, new `poolCandidates()`), which iterates
  `ProjectMPresetManager::presets_` reading `.favorite`
  (src/sources/ProjectMPresetManager.cpp:176-183). `.favorite` is written UNSYNCHRONIZED from the
  message thread by the pre-existing `toggleFavorite()`
  (src/ui/MilkDropBrowser.cpp:49 -> src/sources/ProjectMPresetManager.cpp:224-227, plain
  `presets_[i].favorite = !...`, no lock, no GL confinement). `ProjectMPresetManager` has ZERO
  internal locking anywhere (grep confirmed). Before this diff `getFavorites()`'s only callers were
  in MilkDropBrowser.cpp paint code — message-thread only, so `toggleFavorite()` racing them was
  never live. This diff adds the FIRST GL-thread reader of `.favorite`, activating a previously-
  dormant race. This is exactly the hazard class this repo's OWN same-day notebook entry
  ("2026-09-05 — MilkDrop folder pref (L7)...") documents as closed for `rescan()`/
  `setPresetDirectories()` via `Renderer::rescanMilkDropPresets()`'s `executeOnGLThread(...,
  blockUntilFinished=true)` confinement — and whose "Valid while" clause ("ProjectMPresetManager
  has no internal locking and PresetSelector::processFrame stays GL-thread-only") this new
  Favorites path is the first thing to actually break. `toggleFavorite()` was never brought under
  that fix's confinement (it fixed the rescan path only). Fix: route `MilkDropBrowser::
  toggleFavorite()` calls through `executeOnGLThread` the same way, or make `PresetInfo::favorite`
  synchronized. Narrow window (torn bool read, one frame of stale pool membership at worst — not a
  crash risk in practice) but it is real, TSan-detectable, and in scope (new code, new cross-thread
  edge). The Curated branch (reads `.energy`) is SAFE by contrast — `.energy` mutation is confined
  to `scanDirectory()`, which the prior lane's fix already routes through the GL thread.
  Recommended gate before shipping Pool=Favorites: a TSan run toggling a favorite while Jukebox
  Pool=Favorites auto-switches — cheap, and would almost certainly flag this directly.
