RESOLUME
WEBSERVER

You have successfully enabled
the built-in webserver!

This gives you even greater control over your patch inputs by allowing you to integrate it into even more remote systems and allows you to interact with your patch from virtually any programming language or script.

You can select your own files to be hosted by the Resolume Webserver, or change the directory used to load files to serve in the Preferences window. This page is shown as the default landing page when no index.html file exists in the configured root of the webserver.

To learn how to work with the API, you might want to read the REST API reference.

There is also an example showing the use-case of working with the websocket API

P.S.: Tired of seeing this page? Change the webserver root directory under
Preferences > Webserver, or copy your own index.html to the current directory.
