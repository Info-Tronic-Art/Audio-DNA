Layer Strip Design Study

8 variations exploring layout, density, and Audio-DNA identity expression for the universal layer strip component. Each strip shows an active layer (playing clip, live signals flowing, at least one field in OVERRIDE state). All share the same reference width for direct comparison. Pick 1-2 directions to refine.

Maximum compactness at ~80px. Single-row layout mimicking Resolume density but v10 compliant (no border-radius, blue accent). Smallest footprint; some controls are cramped. Best for setups needing maximum vertical screen space.

V4: Living-Patch

Signal routing as the visual centerpiece at ~105px. 30% controls, 70% patch area. Source columns adjacent to destination columns with animated 1px connection lines. Triangles pulse prominently. SKVF demoted to a mini-grid inset. Strongest Audio-DNA identity expression; most novel layout.

V5: Two-Row-Stacked

Explicit two-row layout at ~120px with clean separation. Top row: playback controls + thumbnail + fade. Bottom row: static sliders + live signals. 4px vertical edge strip at far-left (blue = active, orange top portion = OVERRIDE). Clearest mental model; tallest variation.

Comparison Summary

Variation Height Control Density Signal Density Audio-DNA Identity Recommended Use Case
V1: Resolume-Tight ~80px High (cramped) Low (4 cols, 10px) Low Maximum vertical screen space; Resolume-familiar users
V2: Dense-Current ~115px High (full) Medium (6 cols) Medium Current-build replacement; comprehensive default
V3: Brutalist-Max ~100px Maximum Medium (6 cols) Medium Power users who want every value visible; data-rich monitoring
V4: Living-Patch ~105px Low (compact) High (12 cols) High Audio-DNA showcase; novel routing visualization; demos
V5: Two-Row-Stacked ~120px High (separated) Medium-High (7 cols) Medium Clarity-first; teaching/learning; wide displays
V6: Thumbnail-Centric ~95px Medium Medium (4 cols) Low-Medium Video-heavy workflows; cinematic feel; preview-priority
V7: Signal-Forward ~85px Low (compressed) Maximum (8+ cols) High Audio-first performances; signal monitoring is primary task
V8: Hybrid-Optimal ~95px Medium-High Medium (4+scroll) Medium-High Balanced default; practical + identity; recommended starting point
