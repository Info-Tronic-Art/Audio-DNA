Layer Row Design Study — Part A (V1-V10)
10 variations exploring layer-row composition: strip + cells grid in context. Speed (S) and signal placements vary across variations. No K slider. All variations rendered at 1200px reference width for direct comparison. Categories: A = Traditional+ (V1-V4), B = Speed Reinvented (V5-V8), C = Signal Reinvented first 2 (V9-V10). Part B (V11-V20) in separate file.
